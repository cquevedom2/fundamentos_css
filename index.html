Custom Properties

Las variables CSS se definen en :root y se reutilizan en todo el archivo. Cambiar un valor aquí actualiza el diseño entero.

  • --color-primario #2d6a4f — verde principal
  • --color-secundario #f4a261 — naranja acento
  • 1rem
    --espaciado 1rem — unidad base de espaciado 
:root {
  --color-primario:   #2d6a4f;
  --color-secundario: #f4a261;
  --espaciado:        1rem;
}
